# Examples

`quickstart.py` is the smallest user-facing example: it renders a line chart
and writes `quickstart.png` beside the script.

```bash
python examples/quickstart.py
```

`gallery_render.py` in `tools/` renders the larger example gallery shown on the
project site. `samples.py` and `karios_figures.py` in this directory are the
fixtures that gallery uses; they are not tutorials.
